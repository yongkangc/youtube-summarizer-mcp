# Therapy for the Vibe-Coded Brain

## TL;DR

AI can produce working code while concealing that the learner never understood the problem. The antidote is metacognitive awareness: recognize when your reasoning has failed, pause, explain the problem yourself, and use AI only after forming an approach.

## Core claim

In the cited beginner-programming experiment, every participant completed the task with an AI tutor. Some who offloaded the reasoning believed they had solved it mostly themselves, despite lacking the underlying skill. Vibe coding is therefore useful for shipping familiar work but poor for learning unfamiliar concepts.

## Eight thinking traps

Five general learning traps:

- **Forming:** understand the question but choose the wrong approach.
- **Dislodging:** know an approach is failing but cannot abandon it.
- **Assumption:** correctly solve a different problem from the one asked.
- **Location:** skip a foundational step, think completion is near, then discover structural rework is required.
- **Achievement:** keep patching substantial code that needs redesign.

Three AI-amplified traps:

- **Progression:** AI-generated output advances beyond your understanding, leaving you behind without noticing.
- **Interruption:** autocomplete breaks the mental process before you have formed a solution.
- **Misleading:** plausible but wrong AI advice sends the work down a false path.

## Practical protocol

1. Before prompting, restate the goal, constraints and proposed approach.
2. Give yourself a real thinking pause; confusion is part of problem-solving, not proof of incapacity.
3. Disable or ignore autocomplete while forming the solution.
4. Ask AI for hints, counterexamples or critique before requesting finished code.
5. Explain every accepted line and predict its behavior before running it.
6. When repeatedly patching, stop and reconsider the program structure.
7. After completion, reproduce the core idea without AI.

## Caveat

This is primarily a learning argument, not a ban on AI coding. Experienced developers can delegate familiar implementation while retaining architectural judgment and verification. Novices cannot safely outsource the exact reasoning they are trying to develop.

## YK read

Relevant beyond coding: AI can increase output while degrading calibration. Require an explicit independent thesis before AI assistance, then use the model to attack and extend it—not silently create it.

**One-line conclusion:** use AI to compress execution, never to bypass the struggle that builds judgment.
